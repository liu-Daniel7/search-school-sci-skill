# 中文期刊补数指南（知网 CNKI）

> 分工：**你负责登录**，登录后由 agent 在浏览器里跑检索、翻页、导出；也可全手工。
> 时间：单学院约 40–60 分钟（含分批导出）。

---

## 为什么必须单独补这一步

OpenAlex 基本不收中文期刊。机械、车辆、材料类学院的真实产出里，中文权威期刊往往占三分之一以上：

- 机械工程学报、振动与冲击、仪器仪表学报、中国机械工程、机械设计、光学精密工程……
- 这些在 OpenAlex 里要么没有，要么只有英文题录、且单位字段缺失

**不补这一步，报告会系统性低估，而且低估的正好是"国内影响力"那部分。**

---

## 第 1 步：登录（只有你能做）

三种方式，任选其一：

| 方式 | 适用 | 说明 |
|---|---|---|
| 校园网 IP | 在校内 | 直接访问 cnki.net 即显示"机构用户" |
| CARSI / 统一身份认证 | 校外 | 点知网首页"登录"→"校外访问"→ 选学校 → 用学号密码 |
| 漫游账号 | 校外 | 向图书馆申请，个人账号带机构权限 |

> 登录成功标志：右上角显示**机构名称**，检索结果能点开详情、能导出。
> 让 agent 确认这一点后再往下走——没有机构权限，导出会被拦。

---

## 第 1.5 步：谁来点鼠标

两种模式，按情况选：

**A. agent 代操作（推荐）**
用户只在浏览器里输账号、扫码、过验证码，其余由 agent 完成：打开专业检索、粘贴检索式、切换来源类别、翻页、点导出、把文件存进 `cnki_export/`。
需要 agent 具备浏览器能力（如 ego-browser 技能），并且**不做任何代替登录的操作**。

**B. 用户手工**
用户自己检索导出，agent 只负责最后的合并。适合网络慢、或用户更放心的场景。

> 无论哪种，登录这一步必须由用户本人完成——不要把账号密码交给 agent，也不要让 agent 保存会话。

## 第 2 步：专业检索式（可直接粘贴）

进入 **高级检索 → 专业检索**，粘贴：

```
AF='示例大学' AND AF='智能制造' AND YE BETWEEN('2015','2026')
```

把学校和学院换成自己的。要点：

- `AF` = 作者单位字段（以专业检索页的字段说明为准，个别版本叫 `AF=机构`）
- **必须同时用校名和学院名**，否则会混入其他高校的同名学院（同名院系非常普遍，实测多算过上百篇）
- 学院简写容易漏检，建议补齐系名后 OR：

```
AF='示例大学' AND (AF='智能制造' OR AF='机械工程' OR AF='车辆工程')
```

---

## 第 3 步：按来源类别分别检索（这是中文期刊分级的关键）

知网检索结果左侧可以按**来源类别**筛选。**不要一次导出全部**，而是分五轮，每轮导出成一个文件：

| 轮次 | 来源类别筛选 | 导出文件名 | 合并后层级 |
|---|---|---|---|
| 1 | 北大核心 | `cnki_北大核心.csv` | 中文核心 |
| 2 | CSSCI | `cnki_CSSCI.csv` | CSSCI |
| 3 | CSCD | `cnki_CSCD.csv` | CSCD |
| 4 | EI 来源期刊 | `cnki_EI.csv` | EI(中文) |
| 5 | 全部（再导出一次） | `cnki_全部.csv` | 自动去重后归为中文普刊 |

**为什么这么设计**：知网自带来源类别标记，不需要外部"北大核心目录"，也不需要人工判断期刊等级——这是最省事也最可靠的分级方式。

> 同一篇论文会同时出现在"北大核心"和"全部"里，合并脚本会自动去重（按 DOI + 题名归一化）。

---

## 第 4 步：导出字段（务必勾全）

导出 → 自定义 → 勾选这些字段：

```
题名  作者  作者单位  文献来源  发表时间  被引频次  DOI  来源类别
```

缺 `作者单位` → 判不出是不是本学院的；缺 `被引` → 无法排序。

- 单次导出上限 **500 条**，超了要按年份切片（2015、2016……各导一次）
- 格式选 **CSV 或 Excel** 都行，编码 UTF-8 或 GB18030 都能读

---

## 第 5 步：让 agent 跑合并

把所有导出文件放进一个目录，然后：

```bash
python scripts/cnki_import.py \
  --records 结果.records.json \
  --cnki-dir ./cnki_export \
  --config config.json \
  --out 结果_含中文.xlsx
```

脚本会做四件事：

1. 解析所有 csv/xlsx（自动识别列名，中英文表头都行）
2. 与 OpenAlex 数据去重（DOI + 题名归一化）
3. 按导出文件名判定中文期刊等级
4. 用中文关键词标注学科方向，重出完整工作簿

---

## 第 6 步：核对

跑完看日志三行：

```
cnki_北大核心.csv: 128 行
新增 96 篇｜重复跳过 32 篇｜无题名跳过 0 行
主导 780 篇｜参与 1120 篇（其中中文期刊 96 篇）
```

- **重复跳过**说明 OpenAlex 里已有，正常
- **新增数**应该与"知网总命中数 − 英文/重复"相符
- 打开工作簿"① 看板"，表一末尾应出现 **中文核心/EI/CSCD** 和 **中文普刊** 两列

## 常见坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 导出的 CSV 打开是乱码 | GB18030 编码 | 脚本自动尝试三种编码；仍失败就用 Excel 另存为 UTF-8 CSV |
| 新增数为 0 | 检索式命中的全是 OpenAlex 已有记录 | 检查是不是只导了英文刊；或扩大年份范围 |
| 单位列全是"××大学"没有学院 | 作者没写学院 | 只能靠教师姓名反查（脚本按第一作者匹配教师名单） |
| 一篇文章反复出现在多个文件 | 分轮导出必然重复 | 正常，去重已处理 |
| 导出按钮灰色 | 未登录或权限不足 | 回第 1 步确认机构登录 |
| 中文期刊被判成"中文普刊" | 文件名没带类别关键词 | 重命名文件为 `cnki_北大核心.csv` 等 |

---

## 一句话

**登录 → 专业检索（校名+学院名）→ 按来源类别分五轮导出 → 放进一个目录 → 跑 `cnki_import.py`。**

知网的自带来源类别标记就是最好的中文期刊分级依据，不用另找目录。
